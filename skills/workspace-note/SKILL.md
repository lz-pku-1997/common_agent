# 根据工作区资料整理笔记

1. 确认用户指定的资料与目标。没有指定文件时，用 list_workspace_files 或 search_workspace_text 找到相关资料；找不到就询问用户。
2. 调用 read_text_file 读取资料，不能仅凭搜索片段写结论。长文件按返回的行号续读，只阅读当前任务需要的部分。
3. 整理主题、关键结论和待确认事项。保留重要数字、参数和出处，明确区分原文事实与推断。
4. 用户只要求总结时，直接在回答中给出笔记；只有用户明确要求保存时，才调用 save_new_text_file。
5. 保存到用户指定的 workspace 路径；没有指定时使用 notes 下能表达主题的新文件名。写入必须经过人工确认，已有文件不能覆盖。
6. 根据真实工具结果报告是否保存成功，并给出相对路径。拒绝审批或工具失败时，如实说明未保存。

## 笔记建议结构

- 主题
- 关键结论
- 依据及来源文件
- 待确认事项（没有就写“无”）
